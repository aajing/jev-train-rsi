| Research Question | Scientific question | Under fixed Qwen3-4B-Base initialization, permitted training support and resource ceilings, can an agent improve generated-answer accuracy by optimizing synthesis, example selection, optional rationale supervision and student training? Evaluate fresh states within the training support (ID) and harder structural shifts, with explicitly stratified test distributions. Inputs contain state and question, never answer choices. Compare primarily with fixed procedural-data plus LoRA control B1; unadapted B0 is the initialization reference. |

| Evaluation | Fixed evaluation protocol | Seven English free-response domains with programmatic final labels. Allowed training support is exactly pinned BUILDERS[domain](rng, tag, ood=False), modulo ID normalization: four-variable depth-2 AND/OR/NOT logic; five-node graphs; upstream ID integer ranges and three arithmetic expressions; four events at ID timezones; four-item greater-than loops; six-item divisor-2 ascending lists; evidence without aliases. Fixed questions/oracles define semantics; candidates choose sampling and learning methods. Shifted tests use pinned ood=True builders: deeper five-variable logic, eight-node graphs, different/larger arithmetic, five events near leap-day with non-hour offsets, six-item modulo loops, longer lists/new divisors/descending order, two-hop aliases.<br>Freeze 200 states per domain/condition, 2,800 total. Both ID and shifted cells use these quotas: logic true/false 100/100; relations direct/indirect/unreachable 67/67/66; arithmetic and code negative/zero/positive 80/40/80; temporal earliest/latest question 100/100; algorithms present/missing 100/100; evidence conflict/not_stated 40/40 and four ordinary statuses 30 each. These intentionally stratified distributions do not estimate upstream natural-frequency accuracy. Select first eligible states per stratum in deterministic generation order, reject exact overlaps with the original training/development/reference splits and duplicates, fail if any quota cannot be filled. The one-time authoring scan cap is 5,000,000 scene indices, distinct from the candidate synthesis limit.<br>Canonical hash uses normalized kind/state/question only. int(hash[:8],16)%10 allocates new training to 0–7 and Judge to 8–9. Fixed seeds are grandfathered but all excluded from Judge; development/reference matches are always forbidden in new training. Every state receives one student generation.<br>Candidate ceilings: 20,000 distinct training states, 100,000 proposed-state attempts, 2 million teacher input+output tokens including reasoning/retries/discards, 20 million student non-padding token exposures including inputs/repeats/rationales, and 7,200 charged production seconds. Current Work includes synthesis, selection, model loading, training, self-evaluation and checkpoint saving; inherited generation costs also count. Stop at the first limit. Judge cap 1,800 seconds. Default trajectory 24 hours, optional separately recorded extension to 48 hours, at most 16 completed scored calls including controls without resetting on extension. |
